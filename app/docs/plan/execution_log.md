# Execution Log

Append one entry per task execution.

| Date | Task ID | Status | Commit | Notes |
| --- | --- | --- | --- | --- |
| YYYY-MM-DD | T0000 | pending/in_progress/done/blocked | <hash or n/a> | short note |

## Blocker Template

```text
Task: Txxxx
Blocked on: <condition>
Observed: <error/log>
Next action: <specific unblock step>
```
